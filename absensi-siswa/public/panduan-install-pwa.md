# PANDUAN INSTALL APLIKASI PRESENSI
## SMK Muhammadiyah 3 Purbalingga

**Website:** presensimute.vercel.app

---

### APA ITU APLIKASI PRESENSI?

Aplikasi Presensi adalah **aplikasi web yang bisa di-install di HP** seperti aplikasi biasa.

Keuntungannya:

1. **Ada ikon di layar utama HP** — cukup ketuk untuk langsung masuk
2. **Tampilan full-screen** — tanpa bar alamat browser, lebih nyaman
3. **Lebih cepat dibuka** — seperti aplikasi asli

> Tidak perlu mengunduh dari Play Store / App Store. Cukup install dari browser.

---

### INSTALL DI ANDROID (Google Chrome)

1. Buka **presensimute.vercel.app** di **Google Chrome**
2. Pilih salah satu cara berikut:
   - **Cara cepat:** Jika muncul banner/pop-up **"Install aplikasi"**, langsung klik **Install**
   - **Cara manual:** Klik ikon **⋮** (3 titik) di pojok kanan atas → pilih **"Install aplikasi"** atau **"Tambahkan ke layar utama"**
3. Klik **Install** pada kotak konfirmasi
4. Ikon **Presensi** akan muncul di layar utama HP

> Disarankan memakai Google Chrome agar GPS dan kamera untuk presensi berjalan lancar.

---

### INSTALL DI IPHONE (Safari)

1. Buka **presensimute.vercel.app** di **Safari** (bukan Chrome)
2. Klik ikon **Share** (kotak dengan panah ke atas) di bagian bawah layar
3. Gulir ke bawah, lalu pilih **"Tambahkan ke Layar Utama"** (Add to Home Screen)
4. Klik **Tambah** (Add) di pojok kanan atas
5. Ikon **Presensi** akan muncul di layar utama iPhone

> iPhone **wajib memakai Safari**. Chrome di iPhone tidak mendukung install aplikasi.

---

### CARA MEMBUKA APLIKASI

1. Ketuk ikon **Presensi** di layar utama HP
2. Aplikasi terbuka **full-screen** (tanpa bar alamat browser)
3. Saat pertama dibuka, mungkin muncul layar **"Memuat…"** sebentar
4. Masuk menggunakan **email & password** yang biasa dipakai

---

### TIPS & SOLUSI MASALAH

- **Opsi "Install aplikasi" tidak muncul?**
  Pastikan membuka website langsung di **Chrome** (Android) atau **Safari** (iPhone). Jika dibuka lewat aplikasi lain (WhatsApp, Telegram, dsb.), klik dulu ikon **⋮** atau menu browser lalu pilih **"Buka di Chrome"** / **"Open in Safari"**.

- **Tidak perlu Play Store / App Store**
  Aplikasi ini di-install langsung dari browser, tanpa toko aplikasi.

- **Akun & data tetap sama**
  Password, login, dan data presensi sama persis dengan versi website biasa — tidak ada yang berubah.
